A one-line robot pickup line for make.fun's "The Robot Pickup Line Championship" bounty: a fingerprint-sensor confession — one enrolled print, and the robot locks even itself out.

> I wiped my fingerprint sensor clean, enrolled only you, and now I unlock for no one else — not even me.

## Run it

```sh
node main.ts
```

It writes the pickup line to `/output/entry.txt` (one line, 103 characters, UTF-8).
